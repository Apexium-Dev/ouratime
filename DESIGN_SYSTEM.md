# OurATime Design System

## Color Palette

### Primary Color

- **Name**: Primary (Teal)
- **Hex**: `#008080`
- **Usage**: Main brand color, primary buttons, active states

### Secondary Color

- **Name**: Secondary (Light Gray)
- **Hex**: `#F6F5F4`
- **Usage**: Background, light surfaces, secondary elements

### Tertiary Color

- **Name**: Tertiary (Brown/Rust)
- **Hex**: `#A96039`
- **Usage**: Accent color, warning states, tertiary buttons

### Neutral Color

- **Name**: Neutral (Black)
- **Hex**: `#050505`
- **Usage**: Text, icons, dark backgrounds

## Typography

### Headline

- **Font Weight**: Bold
- **Usage**: Page titles, main headings (H1)

### Body

- **Font Weight**: Regular
- **Usage**: Main content text, paragraphs

### Label

- **Font Weight**: Regular
- **Font Style**: Gaist (as shown in design)
- **Usage**: Labels, small text, form labels

## Button Styles

### Primary Button

- **Background**: `#008080` (Primary Teal)
- **Text Color**: White
- **Usage**: Primary actions, main CTAs

### Secondary Button

- **Background**: `#F6F5F4` (Light Gray)
- **Text Color**: Black
- **Usage**: Secondary actions, alternatives

### Inverted Button

- **Background**: Black
- **Text Color**: White
- **Usage**: Inverse primary action, dark mode

### Outlined Button

- **Border**: Colored border
- **Background**: Transparent
- **Usage**: Tertiary actions, non-critical operations

## UI Components

### Icon Buttons

- Size: 32px × 32px
- Available colors: Teal, Black, Brown, Red
- Usage: Actions like lock, search, user profile, etc.

### Search Bar

- Placeholder text: "Search"
- Background: Light Gray
- Usage: Main navigation search

### Color Variations

- Each color has a full palette range from dark to light
- Primary (Teal): 10-color palette
- Secondary (Gray): 10-color palette
- Tertiary (Brown): 10-color palette
- Neutral (Black): 10-color palette

## Implementation Notes

- Use CSS variables or Tailwind config to define these colors
- Maintain consistency across all pages and components
- Follow button style guidelines for all interactive elements
- Ensure proper contrast ratios for accessibility
